# Security policy

## Supported version

Security fixes target the current `main` branch.

## Reporting a vulnerability

Use GitHub private vulnerability reporting for this repository. Do not open a public issue containing an exploit, sensitive device details, capture data, photos, or exported ZIPs. If private vulnerability reporting is unavailable, contact the maintainer through the GitHub profile before sending details.

Include the affected build timestamp or commit, device and browser versions, reproduction conditions, impact, and the smallest safe proof of concept. Remove unrelated capture data and personal information. Receipt and remediation timelines depend on maintainer availability; no fixed response-time guarantee is made.
